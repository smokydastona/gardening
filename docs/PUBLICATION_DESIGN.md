# Publication design

The complete encyclopedia uses a restrained warm-paper, ink, and evergreen palette with a
6.125 by 9.25-inch book page, embedded text fonts, running headers, page numbers, PDF bookmarks,
and a table of contents.

Scientific names and technical names use text typography rather than decorative handwritten
fonts. Tables, body text, and captions use sufficient contrast and repeatable styles.

## Editorial voice

The reader-facing prose should sound like a competent, observant gardener explaining a decision,
not a generic content-composition system. Preserve the source trail and uncertainty, but vary
sentence length, use concrete details, and connect instructions to the reason for the task.
Avoid repetitive rule-list scaffolding, vague certainty words, and empty summaries that merely
repeat the previous paragraph. Margin notes may be more conversational, but the body, heading,
and margin note must not invent historical ownership or independent evidence.
