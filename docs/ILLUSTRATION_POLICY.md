# Illustration policy

Only hash-bound, human-reviewed sidecars in `human-reviewed-approved` status may enter a
publication. Filename presence is not approval.

The main checkout must contain every approved asset. The separate `illustration-assets` branch
is not a runtime dependency and must not be fetched by the publication build.

Generated, annotated, imported, and existing plates remain pending until identity, botanical
accuracy, provenance, license, reviewer, date, and notes are all recorded.
