# Calendar methodology

`errington_calendar_entries.csv` preserves the original supplied calendar transcription,
including source page, month, section, plant text, and row text.

The project does not infer a planting date for an ambiguous grouped entry. Slash-separated,
comma-separated, and general grouped labels remain visible and receive individual review flags.
Mechanical keyword action labels in `calendar_actions.csv` are classifications, not human
horticultural verification.
